# Do‘stlar Social Network

Build a polished, responsive Uzbek-language social network and chat web app named “Do‘stlar”. Create an MVP with a modern, friendly visual identity: clean light interface, deep indigo/blue accents, rounded cards, excellent mobile layout. Core screens: sign up/login, home feed with post composer, text/photo post cards, likes, comments, user profiles, discover/search people, notifications, and one-to-one direct messages with a conversation list and chat window. Include realistic demo seed content and avatars so the app looks populated on first load. Add navigation for Feed, Discover, Messages, Notifications, Profile. Use secure authentication and a persistent database if available; enforce authorization so users can only edit their own profile/posts and access only conversations they participate in. Do not expose secrets. If full realtime messaging cannot be configured automatically, implement a functional persisted chat with refresh/polling fallback and clearly structure it for realtime upgrade. Include empty/loading/error states, accessible controls, responsive design, and Uzbek UI copy throughout. Do not publish/deploy automatically; create the project and preview only.
